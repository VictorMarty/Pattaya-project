# frontend

The player-facing web client for Pattaya.

- **Stack:** React + TypeScript (mobile-first; static build).
- **Responsibilities (high level):**
  - Create a game and produce a **shareable game id**.
  - Join an existing session by id.
  - Render the board and let the current player take **turn actions**.
- **Hosting:** built to static assets and published to GitHub Pages.

> Not scaffolded yet — this is the placeholder for the React app. The build
> tool (expected: Vite), folder layout, and sync transport are tracked as beads
> issues. See [`docs/architecture/overview.md`](../docs/architecture/overview.md).
