# Pattaya

Мобильная веб-игра (в разработке).

## GitHub Pages

Страница автоматически деплоится через GitHub Actions при пуше в ветки
`main` или `claude/github-pages-setup-SqMB9` (см. `.github/workflows/pages.yml`).

### Первичная настройка (один раз, вручную)

В настройках репозитория нужно включить Pages с источником **GitHub Actions**:

**Settings → Pages → Build and deployment → Source: GitHub Actions**

После этого при каждом пуше сайт будет публиковаться по адресу:

```
https://victormarty.github.io/Pattaya-project/
```

Этот адрес можно открыть с телефона, чтобы видеть результат.
